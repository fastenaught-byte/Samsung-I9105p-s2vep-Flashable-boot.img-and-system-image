# Forking Guidelines

Thank you for your interest in this project!

If you fork this repository, please:

- Keep the original license intact.
- Retain existing copyright notices.
- Document any major changes you make.
- Clearly state that your version is a fork if you redistribute it.
- Consider contributing bug fixes and improvements back to the community.

You are free to modify and redistribute this project under the terms of the GNU General Public License v3.0 (GPLv3).

If you create a public fork, a link back to the original repository is appreciated but not required.

Well have fun contributing to this.
